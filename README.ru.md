# Поток

Торрент-клиент с TUI, мышью, анимацией и EN/RU. Загрузки ведёт собственный
фоновый процесс из того же исполняемого файла. Закрытие TUI не прерывает
передачу; Transmission не нужен.

## Зависимости и сборка

Интерфейс написан на C11. Торрент-движок — libtorrent-rasterbar через адаптер
на C++17. Две основные библиотеки: **ncursesw** и **libtorrent-rasterbar**.
Движку нужны OpenSSL и стандартная библиотека C++; Boost используется при
сборке. Python, libcurl и JSON-парсер не нужны. `fzf` необязателен: без него
работает встроенный поиск файлов. Фоновый режим новых библиотек не требует.

Проверено в Linux с libtorrent 2.1.2. В коде сохранена совместимость API 2.0;
эта версия отдельно не проверена. Минимальный терминал — 80×24, удобнее 108×40.

```sh
# Debian / Ubuntu
sudo apt install build-essential pkg-config libncurses-dev libtorrent-rasterbar-dev

# Arch Linux
sudo pacman -S --needed base-devel pkgconf ncurses boost libtorrent-rasterbar

make
./potok --lang ru
```

По умолчанию сборка использует `-Os`: бинарник 0.3.1 занимает около 1,04 МиБ.
На Intel i5-8365U с GCC 16.2.1 чистый `make -j2` занял 36 секунд,
пересборка только интерфейса — 0,94 секунды. Без торрентов TUI и фоновый
процесс вместе занимали около 27 МиБ RSS; общие страницы библиотек учитываются
в обоих процессах. Это отдельные локальные замеры, не универсальные нормативы.

`sudo make install` устанавливает клиент и справку в `/usr/local`.
Для создания пакета поддерживаются `DESTDIR` и `PREFIX`:

```sh
make DESTDIR="$PWD/stage" PREFIX=/usr install
make source
```

Лицензия проекта — [MIT](LICENSE). Рецепт AUR находится в
`packaging/aur/potok-git`; он использует системные библиотеки. Публикация
в AUR ещё не выполнена. Обычный `make` собирает только клиент, без тестов.

Для локальной разработки сборка также умеет использовать библиотеку и заголовки
из `.deps`, если этот каталог существует. Он не входит в репозиторий;
обычная сборка использует системные библиотеки.

```sh
make bundle
./dist/potok/potok --lang ru
```

`dist/potok` содержит приложение, библиотеку движка и её лицензию.
Системные ncurses, OpenSSL и C++ runtime остаются динамическими зависимостями.
Пакет предназначен для совместимой Linux-системы, а не для любой версии glibc.

## Работа

- Добавление magnet-ссылок, локальных `.torrent` и HTTP(S) URL.
- Загрузка и раздача, проверка частей, DHT и обмен пирами средствами движка.
- Пауза, продолжение, проверка данных, порядок очереди загрузок.
- Выбор скачиваемых файлов, просмотр пиров и трекеров.
- Поиск, фильтры, общие лимиты скорости, EN/RU по клавише `l`.
- `d` / `D` открывают окно удаления с галочкой для удаления данных.

Без галочки торрент удаляется из списка, а файлы остаются. Галочка
«Удалить скачанные файлы» удаляет также полностью или частично загруженные
данные. Она всегда снята при открытии окна; переключение — пробелом или мышью,
подтверждение — Enter, отмена — Esc. Данные удаляются без корзины. Посторонние
файлы в каталоге загрузки и исходный файл `.torrent` сохраняются.

## Добавление

`potok path/to/file.torrent` добавляет файл и открывает интерфейс.
Поддерживаются относительные пути, пробелы и кириллица. Пути с пробелами
заключайте в кавычки; для имени с дефиса используйте `potok -- -file.torrent`.
`potok --background file.torrent` добавляет торрент без открытия TUI.
За один запуск можно передать один источник.

`a` открывает форму с источником и каталогом загрузки. Вставьте magnet-ссылку,
URL или путь к `.torrent`; `Tab` переключает поля, `Enter` добавляет торрент.
Каталог уже заполнен, допускаются абсолютные пути, `~/…` и относительные пути.
Поддерживаются вставка из буфера, кириллица, редактирование в середине строки,
`Home` / `End`, `Ctrl-U` для очистки и `Ctrl-W` для удаления слова.

`f` сразу открывает выбор `.torrent`, `Ctrl-F` или кнопка «Файлы» — из формы.
Если установлен `fzf`, файлы рекурсивно поступают в него во время поиска.
Иначе открывается встроенный список с фильтром по вводимым буквам.
Выбор: `↑ ↓`, `Enter`; отмена: `Esc`. Поддерживаются мышь и имена с пробелами.

По умолчанию поиск охватывает весь домашний каталог. Результаты поступают
в fzf сразу по мере нахождения. После выбора файла корень поиска сохраняется.
Другой постоянный корень задаётся параметром `browse_dir` в настройках.
Для разового поиска в другом месте введите путь к каталогу в поле источника
перед `Ctrl-F`, например `~/torrents/`; к пути можно дописать начало имени.
Поиск не проходит по символическим ссылкам и ограничен 32 уровнями
и 100 тысячами торрентов. Предела по числу остальных файлов нет.

## Фоновая работа и настройки

Обычный запуск автоматически запускает фоновый процесс или подключается к уже
работающему. `q` / `Ctrl-C` закрывают интерфейс, загрузки и раздачи продолжаются.
После закрытия терминала процесс также остаётся работать. `Q` в интерфейсе
останавливает его после подтверждения. Управление без TUI:

```sh
./potok --background   # запустить загрузки без интерфейса
./potok --status       # состояние и PID
./potok --stop         # сохранить состояние и остановить загрузки
```

Настройки создаются в `$XDG_CONFIG_HOME/potok/config` или
`~/.config/potok/config`. Пример (замените `/home/user` своим домашним каталогом):

```ini
language=ru
download_dir=/home/user/Downloads
state_dir=/home/user/.local/share/potok
browse_dir=/home/user
```

Язык, выбранный клавишей `l`, и изменённый в форме каталог загрузки
сохраняются автоматически. В файле настроек пути абсолютные.
Редактируйте его между запусками интерфейса; изменение `state_dir` переключает
профиль и не переносит старые загрузки. Сначала остановите старый процесс.

По умолчанию состояние хранится в `$XDG_DATA_HOME/potok` или
`~/.local/share/potok`, как и в предыдущей версии. Параметры запуска временно
переопределяют настройки:

```sh
./potok --download-dir /data/downloads --state-dir /data/potok
./potok --config-dir /path/to/private/config
```

Каталог состояния должен принадлежать пользователю и иметь права `0700`:
resume-файлы содержат пути и адреса приватных трекеров. На один каталог работает
один фоновый процесс; к нему могут подключаться несколько интерфейсов.
Настройки и состояние заменяются атомарно. Очередь, прогресс, паузы и лимиты
сохраняются при остановке процесса и периодически во время работы.
`control.sock` и `worker.log` находятся в каталоге состояния; доступ к сокету
имеет только текущий пользователь. Для `--status` и `--stop` укажите те же
параметры профиля, с которыми запускали загрузки.

Автозапуск при загрузке ОС не устанавливается. После перезагрузки запустите
`potok` или `potok --background`; сохранённые загрузки восстановятся.

Лимиты задаются в КиБ/с; `0` снимает ограничение. Тихий режим ограничивает
загрузку до 128 КиБ/с и отдачу до 64 КиБ/с, сохраняя более низкие пользовательские
лимиты. Метаданные `.torrent` ограничены 4 МиБ; размер загружаемых файлов
этим не ограничен. При загрузке `.torrent` по HTTPS проверяется сертификат.

Фон наследуется от терминала. Его прозрачность задаётся в настройках терминала;
Potok не устанавливает непрозрачную заливку. Выделенная строка сохраняет свой цвет.

## Управление

| Клавиша | Действие |
|---|---|
| `↑ ↓` / `j k` | Выбор строки |
| `Tab` | Фокус списка / подробностей |
| `← →` | Обзор / файлы / пиры / трекеры |
| `1` … `5` | Фильтры |
| `a` | Добавить торрент |
| `f` / `Ctrl-F` в форме | Выбрать `.torrent` |
| `Space` / `p` | Пауза / продолжение |
| `Space` в списке файлов | Скачивать / пропустить файл |
| `/` | Поиск; пустой запрос сбрасывает фильтр |
| `v` | Проверить данные |
| `K` / `J` | Выше / ниже в очереди загрузок |
| `t` | Тихий режим |
| `s` | Лимиты скорости |
| `d` / `D` | Окно удаления с галочкой «Удалить скачанные файлы» |
| `l` | EN / RU |
| `?` | Справка |
| `q` / `Ctrl-C` | Закрыть TUI, продолжить загрузки |
| `Q` | Остановить загрузки и выйти после подтверждения |

Мышь выбирает строки, вкладки, фильтры, кнопки и флажки файлов. Колесо
прокручивает список под указателем. Выделение текста — обычно с Shift.
При высоте меньше 32 строк `Tab` открывает подробности вместо списка.

`--lang en` / `--lang ru` задаёт язык запуска. Без параметра используется
сохранённый язык; при первом запуске учитываются `LC_ALL`, `LC_MESSAGES`, `LANG`.
`./potok --demo` открывает анимированный просмотр без сети и изменения файлов.

## Проверки

```sh
make test
make sanitize
./tests/test --snapshots
```

Тесты проверяют ввод, вставку UTF-8 по одному байту, EN/RU, прозрачный фон,
изменение размеров и настоящие SGR-события мыши в PTY. Проверяются настройки,
поиск файлов и выбор через настоящий `fzf`, если он установлен.
Интеграционные тесты запускают встроенные движки
на loopback: magnet, обмен метаданными, передача файла, пауза, восстановление,
выбор файлов, проверка данных и оба режима удаления. Дополнительно проверяются
HTTP-импорт, права доступа и блокировка каталога состояния. Отдельный тест
проверяет получение всего файла без подключённых клиентов, повторное
подключение к тому же процессу и сохранение состояния при его остановке.
Публичный swarm
для этих проверок не используется.

Нет создания торрентов и редактирования трекеров. Совместимость с конкретным
публичным трекером и macOS отдельно не проверена.
