<p align="center"><sub>Деморежим Potok. Загрузки в ролике показаны на примере тестовых данных.</sub></p>

Добавьте magnet-ссылку, локальный `.torrent` или HTTP(S) URL торрента.
Клавиатурой и мышью можно ставить загрузки на паузу, выбирать файлы и смотреть
пиров. Закрытие терминала не прерывает загрузки.

## <img src="docs/assets/terminal.svg" width="22" height="22" alt=""> Сборка

```sh
# Arch Linux
sudo pacman -S --needed base-devel pkgconf ncurses boost libtorrent-rasterbar

# Debian / Ubuntu
sudo apt install build-essential pkg-config libncurses-dev libtorrent-rasterbar-dev

make -j2
./potok
```

Интерфейс написан на C11, адаптер libtorrent — на C++17. Для работы нужны
ncursesw, libtorrent-rasterbar, OpenSSL и системные библиотеки C/C++.
Заголовки Boost нужны при сборке. Необязательные инструменты: `fzf` для поиска
файлов и `xdg-open` для открытия папки загрузки.

Проверено в Linux с libtorrent 2.1.2. Минимальный размер терминала — 80×24;
при 108×36 и больше остаётся больше места для подробностей. Фон и прозрачность
наследуются от терминала.

`sudo make install` устанавливает клиент в `/usr/local`. Для сборки пакета:
`make DESTDIR="$PWD/stage" PREFIX=/usr install`. `make source` создаёт архив
исходников, `make bundle` — каталог `dist/potok/` с копией libtorrent.
Для этого пакета по-прежнему нужны совместимые системные библиотеки.

[PKGBUILD для Arch](packaging/aur/potok-git/PKGBUILD) есть в репозитории.
В AUR пакет пока не опубликован.

## <img src="docs/assets/folder.svg" width="22" height="22" alt=""> Найти торрент

```sh
potok path/to/file.torrent
potok "$HOME/Downloads/мой файл.torrent"
potok --background file.torrent
```

Нажмите `a`, чтобы вставить ссылку или выбрать файл. Форма показывает каталог
назначения и свободное место. `Tab` переключает поля, `Enter` добавляет торрент.

![Поиск torrent-файлов в дереве каталогов](docs/assets/search.gif)

`Ctrl-T` открывает дерево. Вводите запрос, раскрывайте ветки стрелками `← →`
или мышью, выбирайте файл по `Enter`. Клавиша `f` открывает fzf, если он установлен,
иначе встроенное дерево. По умолчанию поиск охватывает домашний каталог.
Постоянный корень задаётся в `browse_dir`; для разового поиска в другом месте
введите каталог в поле источника. Дерево появляется после сканирования.
Поиск не проходит по символическим ссылкам и ограничен 32 уровнями
и 100 тысячами torrent-файлов.

Кнопка «Выбрать папку» или `Ctrl-F` в поле назначения открывает список папок.
`Enter` входит в папку, `←` переходит выше, `F2` выбирает текущую папку.

## <img src="docs/assets/transfers.svg" width="22" height="22" alt=""> Управление

| Клавиша | Действие |
|---|---|
| `↑ ↓` / `j k` | Выбрать торрент |
| `a` / `f` | Добавить источник / найти torrent-файл |
| `p` / `Space` | Пауза / продолжение |
| `Enter` | Открыть папку загрузки |
| `Tab` / `← →` | Переключить панель / вкладку подробностей |
| `1` … `5` / `/` | Фильтр по состоянию / названию |
| `s` / `t` | Лимиты скорости / тихий режим |
| `v` / `K J` | Проверить данные / переместить в очереди |
| `d` | Удалить торрент; при необходимости вместе с файлами |
| `q` / `Ctrl-C` | Закрыть интерфейс, продолжить загрузки |
| `Q` | Остановить загрузки после подтверждения |
| `?` | Все горячие клавиши |

Мышь выбирает строки, вкладки, кнопки и флажки файлов; колесо прокручивает список.
«Загруженные» включает завершённые торренты на паузе. В статусе «Раздача» клиент
готов отдавать скачанные данные другим пирам.

В окне удаления оставьте галочку «Удалить скачанные файлы» снятой, чтобы
сохранить данные. С галочкой удаляются также полные или частичные загрузки,
без корзины. Посторонние файлы и исходный импортированный `.torrent` остаются.

## <img src="docs/assets/background.svg" width="22" height="22" alt=""> Фоновая работа

Potok запускает фоновый процесс автоматически. `q` закрывает интерфейс,
повторный запуск `potok` подключается к тому же процессу. Команды без интерфейса:

```sh
potok --background
potok --status
potok --stop
```

Автозапуск при загрузке ОС не устанавливается. После перезагрузки запустите
`potok` или `potok --background`, чтобы продолжить сохранённые загрузки.
Для запуска, проверки и остановки указывайте одни и те же параметры профиля.

## Настройки

По умолчанию файлы скачиваются в `~/Downloads`. Настройки хранятся в
`~/.config/potok/config`, состояние — в `~/.local/share/potok`.
Поддерживаются `XDG_CONFIG_HOME` и `XDG_DATA_HOME`. В конфиге нужны абсолютные пути:

```ini
download_dir=/home/user/Downloads
state_dir=/home/user/.local/share/potok
browse_dir=/home/user
```

Каталог назначения запоминается после успешного добавления торрента.
`--download-dir`, `--state-dir` и `--config-dir` переопределяют настройки.
Изменение `state_dir` выбирает другой профиль, но не переносит загрузки.
Ограничьте доступ к каталогу состояния: resume-файлы могут содержать адреса трекеров.
Клавиша `l` меняет и сохраняет язык; `--lang en|ru` задаёт язык на один запуск.

## Разработка

```sh
make test
make sanitize
```

Тесты проверяют ввод в терминале, мышь, поиск файлов, настройки и передачу
по BitTorrent на loopback, включая перезапуск процесса и удаление данных.
Публичные раздачи в автоматические тесты не входят. При ручной проверке
2026-10-24 образ Debian netinst был скачан целиком и совпал с официальным SHA-256.

В настройках libtorrent по умолчанию локальные пиры могут обходить общие
лимиты скорости. После паузы показатели скорости снижаются с задержкой
в несколько секунд. Создание торрентов и редактирование трекеров не реализованы.
macOS, приватные трекеры и длительная непрерывная работа отдельно не проверены.
